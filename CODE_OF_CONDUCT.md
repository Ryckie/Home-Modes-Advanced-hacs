# Code of conduct

This project is a small community effort. To keep it useful for everyone:

- Be respectful. Criticise code and ideas, not people.
- No harassment, discrimination, personal attacks, or unwelcome sexual attention.
- Assume good faith, and say so when you are unsure what someone meant.
- Keep issues and discussions on topic and include what is needed to reproduce a problem.
- Do not publish other people's private information (addresses, tokens, device identifiers).

## Enforcement

The maintainer may edit or remove comments, close issues, and block users who break these
rules. To report a conduct problem, use GitHub's "Report content" feature on the comment, or
open a private security advisory draft and mention that it is a conduct report.

This code of conduct is written for this project. It is inspired by common community
guidelines such as the Contributor Covenant.
